# Security policy

## Supported versions

Security fixes are released for the latest version only.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier than 1.0 | No |

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

Report it privately through GitHub: open the [Security tab](https://github.com/AndreLucas23/personal-blog-site/security) of this repository and choose **Report a vulnerability**, or go straight to the [report form](https://github.com/AndreLucas23/personal-blog-site/security/advisories/new). Only the maintainer sees the report.

Include what helps to reproduce and assess the problem:

- the version or commit affected
- the steps to reproduce it
- what an attacker gains from it

This is a personal project with one maintainer, so an answer can take a few days. A confirmed vulnerability is fixed in a new release and described under `Security` in the [changelog](CHANGELOG.md), with credit to the reporter if they want it.
